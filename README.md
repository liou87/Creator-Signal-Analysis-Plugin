# 创作者信号分析插件

在 B 站 UP 主空间页一键分析，给出该创作者的**商业化程度指数**（0–100），并说明分数含义、计算方式和每一条依据。

> 状态：代码已完成并通过单元测试与构建；**尚未在真实的 B 站页面上验证数据提取**。当前进度见 [docs/DECISIONS.md](docs/DECISIONS.md) 末尾的「进度」一节。

## 这个分数是什么

**商业化程度指数**衡量一个创作者**公开内容中可观察到的变现行为的强度与广度**。

- 使用场景是**线索筛选**：给创作者提供服务或工具的团队，用它判断某个创作者是否在认真做生意、值不值得联系。
- 它**不是**收入估计，**不是**内容质量评价，也**不是**违规判定。
- 分数由公开的规则公式算出，大模型只负责把内容归类为证据，不直接给分。同一份输入永远得到同一个分数。

分数怎么算、每个参数为什么是这个值，见 [docs/DESIGN.md](docs/DESIGN.md)。

## 怎么读报告

| 报告内容 | 含义 |
|---|---|
| 分数与三档（低 / 中 / 高） | 点估计 |
| 区间 | 下界只算确证的证据（明确披露、带货链接）；上界把「疑似软广」全部算上 |
| 内容层 / 账号层子分 | 「多频繁地在内容里做商业」与「搭建了多少变现渠道」 |
| 证据列表 | 每条命中的视频、档位、原文引用，可点击跳回原视频核对 |
| 置信度 | 分析了多少条视频、覆盖多长时间、哪些项没能检查到 |

## 安装

需要 Node.js 20 以上和 Chrome。

```bash
npm install
npm run build
```

然后在 Chrome 里：

1. 打开 `chrome://extensions`
2. 打开右上角的「开发者模式」
3. 点「加载已解压的扩展程序」，选择本项目下的 `.output/chrome-mv3` 目录

## 使用

1. 打开任意 B 站 UP 主的空间页，例如 `https://space.bilibili.com/<UID>`
2. 点浏览器工具栏里的插件图标，右侧出现侧边栏，显示识别到的创作者
3. 点「开始分析」，等待进度走完
4. 查看报告：分数与区间 → 这个分数是什么 → 怎么算的 → 主要依据 → 置信度与局限

报告底部的「数据来源自检」列出了每一项数据是从哪条路径取到的、是否成功。分数看起来不对时先看这里。

### 模型（可选）

不配置也能完整使用。在侧边栏底部的「模型设置」里填入 OpenAI 兼容接口的地址、Key 和模型名之后，「疑似软广」一档改由模型判定。明确披露和带货转化两档始终只由规则判定，分数始终由公式算出。

Key 只保存在本机浏览器的本地存储里，不会进入仓库。
