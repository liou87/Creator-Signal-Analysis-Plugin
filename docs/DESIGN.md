# 指数设计

本文回答三个问题：这个分数衡量什么、怎么算、每个数字凭什么。

## 1. 定义

**商业化程度指数（0–100）**：一个创作者**公开内容中可观察到的变现行为的强度与广度**。

- **使用者**：给创作者提供服务或工具的团队。
- **支持的决定**：这个创作者是否在认真做生意，值不值得联系。
- **因此**：品牌合作、自营带货、知识付费、粉丝付费**全部计入**。对线索筛选来说，它们都说明此人有经营行为。

它不是收入估计，不是内容质量评价，不是违规判定。

**能看到的只是公开文字**：标题、简介、标签、置顶评论、平台标记，以及空间页上的入口。视频里的口播看不到，所以：

- 指数衡量的是「**公开文字中可见的**商业化程度」。口播商单仍然属于商业化（见 1.1），只是测不到，所以不从定义里拿掉。
- 这个偏差**在不同变现方式之间并不均匀**：带货要挂链接，看得全；品牌商单多在口播里，看得少。以接商单为主的创作者会被系统性低估。真实例子：极客湾商单很多，但文字里几乎没有痕迹，得 14–17 分，档位「低」。
- 所以「分数是下界」这个说法不够准确：对不同的人，它低估的幅度不同。报告「这个分数是什么」一节写明了这一点。（D-50）

> 使用场景是从需求推断出来的：需求举的两个信号例子是「商业化程度」和「公开求助意愿」，合起来是「有没有生意、有没有需求」，这是线索评分的典型结构。见 [DECISIONS.md](DECISIONS.md) D-01。

### 1.1 商业化有哪些表现

商业化就是创作者把内容或观众换成钱。按**谁在付钱**分，只有四个方向；每个方向下面是 B 站上具体的变现形式。（D-39）

| 付钱方 | 创作者卖的是 | 具体表现 | 落在 | 公开页面上怎么认出来 | 本工具 |
|---|---|---|---|---|---|
| 品牌方 | 观众的注意力 | 商单视频 | 单条视频 | 文字声明（「本期由 XX 赞助」）、法定广告提示语、推广短链 `b23.tv/cm-` | 部分：写出来的能认，口播的看不到 |
| | | 口播 / 中插广告 | 单条视频 | 只在声音和画面里 | 看不到 |
| | | 商务合作联系方式 | 账号 | 简介 | 能 |
| 买家 | 商品 | 带货视频 | 单条视频 | 置顶评论蓝链 `b23.tv/mall-`、淘口令、优惠码 | 能 |
| | | 自营店铺、周边 | 视频和账号 | 视频里「我们的店」「周边开售」；简介「店铺名：」 | 能（网页上看不到小店入口，只能看文字） |
| | | 直播带货 | 直播 | 只在直播间里 | 看不到 |
| 粉丝 | 内容或关系 | 会员视频（充电专属） | 单条视频 | 详情接口的平台标记 | 能 |
| | | 充电 | 账号 | 接口；有会员视频即可推出 | 部分 |
| | | 课程（B 站课堂） | 账号 | 课程计数接口；视频里推课程的文字 | 能 |
| | | 站外付费社群（知识星球、爱发电） | 账号 | 简介 | 能 |
| | | 付费合集 | 单条视频 | 未查清 | 未覆盖 |
| | | 直播打赏、舰长 | 直播 | 金额不公开 | 看不到 |
| 平台 | 播放量 | 创作激励、广告分成 | — | — | **不计入**，见 1.3 |

站外的生意（淘宝店、知识星球）不是第五个方向，只是前三种发生在站外，B 站页面上只留下一个指向它的线索。

### 1.2 一个信号要计入，必须同时满足

1. **指向某一种付钱方。**「讲商单」「提到某个品牌」只是话题，不算。
2. **是创作者主动做的。** 平台自动加的搜索词链接不算（D-30）。
3. **公开可见。** 看不到的不能计分，只能写进局限说明。
4. **能给出原文证据。** 引用必须是输入文本的子串。

### 1.3 明确不算的

| 情况 | 为什么 |
|---|---|
| 创作激励、播放分成 | 平台按播放量自动发钱，创作者没有做商业决定；外面也看不到 |
| 讲商单、讲广告行业的视频 | 是话题不是交易，不满足第 1 条。所以「恰饭」这类词只算疑似（D-41） |
| 只提到品牌、自费测评 | 没有钱流向创作者 |
| 机构认证、MCN 签约 | 是组织形式，不对应任何一种付钱方（D-40） |
| 有直播间 | 开了直播间不等于有人付钱，不满足第 1 条 |
| 公众号、小红书等只拉关注的站外账号 | 同上（D-40） |
| 创作者自己的抽奖、关注、点赞、转发等互动 | 看不出有谁在付钱，不满足第 1 条（D-48） |

### 1.4 程度怎么量

「程度」拆成两个问题：**多频繁**（最近的作品里有多大比例在变现，对应内容层）和**多少条渠道**（开通了几种变现途径，对应账号层）。见第 2 节。

## 2. 结构

```
指数 = 内容层（0–60） + 账号层（0–40）
```

- **内容层**回答「他多频繁地在内容里做商业」（强度）。
- **账号层**回答「他搭建了多少变现渠道」（广度）。

只看内容层，会漏掉靠店铺或课程变现但视频里不提的人；只看账号层，会高估只开了充电的人。

用加法而不是乘法：变现渠道互为替代，一个创作者只靠其中一种也算在做生意，应当允许两层互相补偿。几何平均会把单渠道创作者压到接近 0。（D-02）

60/40：内容层是持续发生的行为，账号层是一次性的配置，行为的证据力更强。这里只主张「内容 > 账号」这个顺序，不主张 60/40 这个精确比例，用敏感性分析检验（D-07）。

## 3. 内容层（60 分）

### 3.1 取样

最近 30 条视频，且不早于 12 个月前。报告中写明实际覆盖的时间段。

只按条数取，日更的人只覆盖一个月、月更的人覆盖两年半，可比性差；只按时间取，低产的人样本太少。所以两个条件同时用。（D-04）

**为什么只看最近**：使用场景是线索筛选，要回答的是「这个人现在值不值得联系」。

**这个取法的三个代价**（D-45，如实写进报告的局限）：

1. **时间口径不同。** 30 条在真实数据上覆盖的时间从 3 周（共青团中央）到 10 个月（何同学）不等。
2. **受大促季节影响。** 窗口如果落在 618、双 11 期间，带货占比会偏高。
3. **抽样误差大。** 30 条里 8 条确证，真实比例大致在 0.14 到 0.44 之间（Wilson 95% 区间）；18 条里 4 条，大致在 0.09 到 0.45 之间。报告里的区间只反映疑似档的不确定，**没有包含这部分误差**。所以只分三档（D-15），分数接近的两个人不能据此排先后。

考虑过的改法：取 60 条（误差只缩小约三成，请求翻倍，更容易被风控拦截）；在一年里均匀抽 30 条（时间更可比，但只有列表接口成功时才拿得到足够长的列表，抽样方法会随接口成败而变）；把抽样误差算进区间（区间会宽到几乎总是跨档，报告给不出结论）。都没有采用。

**窗口之外只展示、不计分。** 取到的视频里早于 12 个月的那些，用规则检查有没有确证的商业内容（只看 A、B 两档），在报告里单列一块「窗口之外（不计分）」。它用来区分「从来不做」和「以前做过、最近不做」（如所长林超、一个最近一年只发了 1 条的小号）。这些视频的详情在提取时已经取到，不多发请求。

### 3.1.1 取不到视频时不给指数

取不到视频不等于没有商业内容。窗口内一条样本都没有时，要看视频列表是怎么来的：

| 视频列表的来源 | 窗口内 0 条意味着 | 处理 |
|---|---|---|
| 接口返回了最近投稿 | 这位创作者最近 12 个月确实没有投稿（或根本没有投稿） | 内容层按 0 计，报告里写明最新一条的发布时间 |
| 只是当前页面上看得到的视频 | 不知道。页面上显示的可能是代表作，不是最新投稿 | **内容层未能评估，不给指数** |
| 只是当前页面上看得到的视频，窗口内有，但少于 10 条 | 同样不知道：这几条不一定是最近的，又太少 | **内容层未能评估，不给指数**（D-44） |
| 所有路径都没走通 | 不知道 | **内容层未能评估，不给指数** |

「不给指数」时报告显示「本次无法给出指数」，账号层结果照常展示，但明确说明它只是指数的一部分。

注意区分：视频列表来自接口（即真正的最近投稿）时，窗口内只有几条说明「这位创作者最近确实发得少」，这是真实信息，照常给指数，只把置信度标为低。

这与账号层的三态（有 / 无 / 未能检查）是同一个原则。区别在于：账号层某一项未能检查，只是少了几分的信息；内容层占 60 分，未能评估时剩下的数字不足以称为指数。（D-27）

### 3.2 证据档位

每条视频归入它命中的最高一档：

| 档 | 证据 | 权重 | 由谁判定 |
|---|---|---|---|
| A 明确披露 | 广告或商业合作声明；「感谢 XX 赞助」；品牌方提供样品；法定广告提示语 | 1.0 | 规则 |
| B 直接变现 | 带货：购物链接（含 B 站商品短链 `b23.tv/mall-`）、商业推广链接（B 站广告短链 `b23.tv/cm-`）、优惠码、置顶评论导购、自营店铺。付费内容：付费课程、充电专属视频 | 1.0 | 规则 |
| C 疑似软广 | 具体品牌或产品 + 行动引导（专属福利、限时、去哪买），但无披露、无链接；或「恰饭」「金主爸爸」这类口语 | 0.5 | 模型；无模型时为关键词组合 |
| D 无 | — | 0 | — |

具体规则及编号见 `src/classify/rules.ts`，每条证据在报告里都带规则编号。

两点补充：

- **视频简介里的商务联系脚注不算披露。** 很多创作者在每条视频简介末尾写「商务合作：邮箱」。这说明账号在接商单，但不说明这一条视频是广告。所以规则匹配前先把这类脚注剔除，改计入账号层的「商务合作联系方式」。（D-20）
- **B 档叫「直接变现」，包含带货和付费内容两类。** 报告里会分别列出条数，让人看出分数主要来自哪一种（D-35）。
- **充电专属内容计入 B 档。** 它不是「推荐商品」，但视频本身就是付费产品，对线索筛选来说同样是确证的变现行为。类型标为「粉丝付费」。（D-21）
- **法定广告提示语算 A 档。**《广告法》第十六条要求医疗器械广告标明「请仔细阅读产品说明书或者在医务人员的指导下购买和使用」、非处方药广告标明「请按药品说明书或者在药师指导下购买和使用」，第十八条要求保健食品广告标明「本品不能代替药物」。这些话只有广告才必须写，出现即可认定。代价是只覆盖这几类商品。（D-42）
- **「恰饭」「金主爸爸」「商单视频」只算疑似。** 它们既可能是自己承认恰饭，也可能只是在讲商单这个话题（真实例子：《800w粉丝，我们是如何在B站做商单视频的？》）。规则分不清，所以放进 C 档，有模型时由模型区分。（D-41）
- **创作者为自己账号发起的互动不算疑似**：抽奖、送福利、关注、点赞、投币、转发。从这类话术看不出有谁在付钱，不满足 1.2 的第 1 条（真实例子：「准备了 100 台新 iPhone 送给大家，记得去动态参与抽奖」）。这条写在模型提示词里；关键词规则本来就不认这类说法。（D-48）

**C 档由谁判定**：配置了模型且模型判完了所有待定视频时，C 档只采用模型的结论；否则 C 档整体退回关键词。两种口径不混用，报告里会注明本次用的是哪一种。（D-22）

各档的依据：

- **A** 是创作者自己承认的，没有争议。
- **B** 有法规定义：《互联网广告管理办法》第九条规定，以知识介绍、体验分享、消费测评等形式推销商品并附加购物链接等购买方式的，应当显著标明「广告」。也就是说「推荐 + 购买方式」在法规上就是广告，不需要我们主观判断。
- **C** 存在的理由：研究发现绝大多数赞助内容并未披露，只看 A 和 B 会严重低估。但它需要判断，所以权重打折，且要求有「行动引导」而不是仅仅提到品牌 —— 否则测评类创作者会被大面积误报。（D-08）

特征（链接模式、优惠码、披露用语）来自赞助内容检测的学术研究，见第 7 节。

### 3.3 公式

```
r̂        = Σ(每条视频的权重) / (n + k)        k = 5
内容层   = 60 × min(1, r̂ / r_cap)             r_cap = 0.26（由样本定，D-46）
```

- **`+ k` 的作用**：样本少时把占比向 0 收缩。不加的话，只发了 3 条视频、其中 2 条是广告的人会得到 67% 的占比直接满分。加了之后：3 条 2 广告 → 0.25；30 条 10 广告 → 0.29。代价是低产创作者被系统性压低，这与「宁可低估」的整体取向一致。（D-03）
- **`r_cap`**：占比达到多少算这一维满分。这是新榜指数「用样本基准做标准化」的做法（D-05）：初值 0.5 是假设，验证时发现商业内容最密的创作者也只有 0.37，内容层实际上没人能拿满分（D-37）；现在取 10 位验证样本占比的 90 分位数，保留两位小数（D-46）。最初算出 0.256，取 0.26；D-49 修正店铺规则后，大物是也多了 1 条确证，90 分位数变为 0.281，按同一办法改为 **0.28**（D-51）。样本只有 10 位，且是有意挑的两头，不是原计划的约 20 位跨分区创作者，这个数并不稳定：10 个数的 90 分位数基本就是第二大的那个值，一条视频的改判就让它变了 0.025。两次取值下十个人的分档完全相同。`tests/calibration.test.ts` 用真实评分函数重算这 10 位，改参数时会检查区分度和分档是否还成立。

### 3.4 区间

C 档的权重 0.5 是先验，没有数据支撑（原因见第 6 节）。所以报告同时给出区间：

| | C 档权重 |
|---|---|
| 下界 | 0（只算确证的） |
| 点估计 | 0.5 |
| 上界 | 1（疑似的全算） |

区间越宽，说明这个创作者的分数越依赖「疑似」证据。（D-06、D-15）

**总分的区间还要算上账号层里「未能检查」的项。** 未能检查的项不扣分（点估计和下界里按 0 算），但它们可能是「有」，所以上界假定它们全部为「有」：

```
总分下界 = 内容层下界 + 账号层已确认的分数
总分上界 = 内容层上界 + 账号层已确认的分数 + 未能检查的项的分值之和
```

区间的含义因此是：**从「只算已经确认的」到「不确定的全部成立」**。两端落在不同档位时，报告会明说「按现有信息还不能确定属于哪一档」。（D-29）

## 4. 账号层（40 分）

| 指标 | 付钱方 | 分值 | 级别 | 从哪里看 |
|---|---|---|---|---|
| 商务合作联系方式 | 品牌方 | 11 | 强 | 简介；或至少 2 条视频简介的脚注 |
| 公开说明的店铺（站内小店或站外网店） | 买家 | 11 | 强 | 简介（如「店铺名：」「淘宝搜 XX」）；样本视频里引导去自家店铺（如「去我首页小店里看一下」，D-49）；页面上的小店入口（网页上未见过） |
| 付费课程 | 粉丝 | 6 | 弱 | 课程计数接口 |
| 站外付费社群（知识星球、爱发电、付费群） | 粉丝 | 6 | 弱 | 简介 |
| 充电 | 粉丝 | 6 | 弱 | 接口；样本里有充电专属视频 |

只分强弱两级。划分标准是「商业意图的明确程度」：留商务联系方式、开店，是为了做生意而专门做的配置；课程、社群、充电面向已有的粉丝，门槛低、区分度弱。

这些分值是先验设定，不是数据拟合的 —— 样本量不足以拟合。这里只主张「强高于弱」这个顺序，不主张 11 : 6 这个比例，并用敏感性分析检验排序对具体数值是否敏感。（D-07、D-40）

**每一项都对应第 1.1 节里的一种付钱方。** 原先的「机构 / MCN」和「站外导流」里的公众号、小红书不对应任何付钱方，已删除；原先的「小店入口」在网页上看不到，改为看简介里写没写店铺。（D-40）

每个指标有三种状态：**有 / 无 / 未能检查**。页面结构变了导致没抓到时记为「未能检查」，不扣分，但计入总分区间的上界，并降低置信度。（D-13、D-29）

什么时候敢说「无」，各项不同：

| 指标 | 说「无」的条件 |
|---|---|
| 商务联系方式、站外付费社群 | 取到了个人简介，里面没写。所以这几项的「无」准确地说是「简介里没写」 |
| 公开说明的店铺 | 简介里没写，样本视频里也没有引导去自家店铺。B 站小店的入口只在手机端首页，网页上看不到，所以这一项衡量的就是「有没有公开说明」：没有任何公开说明的店铺，不满足 1.2 第 3 条「公开可见」，判「无」是准确的，不是「没抓到」（D-49） |
| 课程 | 课程计数接口返回 0（D-38） |
| 充电 | 只有接口明确返回「未开通」。充电是页头的按钮，不在导航栏里，页面上没看到不能说明没有（D-31）。反过来，样本里有充电专属视频时直接判「有」（D-34） |

## 5. 输出

- 分数、区间、三档（低 / 中 / 高，分界 33 / 66）。验证后保留原值：低分组和有可见商业痕迹的一组在 6 到 17 分之间就分开了，「低 / 中」不必为此移动；「中 / 高」没有公认的极高样本可对照，仍是先验（D-46）
- 内容层、账号层两个子分，以及逐项得分
- 变现类型分布：品牌合作 / 商品带货 / 自营带货 / 知识付费 / 粉丝付费（不影响分数，帮助判断此人做的是哪种生意）。「商品带货」指挂了商品链接、但分不清是自营还是分销；只有明确写了「我的店铺」之类才标「自营带货」
- 证据列表：视频标题、档位、类型、原文引用、判定来源（规则 / 模型）、跳转链接
- 窗口之外（不计分）：取到的、早于窗口的视频里有几条带确证的商业内容，最新一条是什么时候（D-45）
- 置信度：样本数、覆盖时间段、未能检查的项
- 固定的局限说明
- 报告头：昵称、UID、分析时间

只用三档而不是五档：校准样本只有二十个左右，支撑不了更细的分辨率。（D-15）

### 置信度

置信度描述的是「这次分析的数据够不够」，与分数高低无关：

| 级别 | 条件 |
|---|---|
| 低 | 样本少于 10 条视频，或内容层未能评估 |
| 中 | 样本够，但账号层有「未能检查」的项，或视频列表只是当前页面上看得到的部分 |
| 高 | 样本够，视频列表来自接口，且各项都检查到了 |

没有使用模型时，报告会额外提示「疑似软广仅靠关键词识别，可能漏判」，但不因此降级 —— 这影响的是区间上界的可靠性，区间下界不受影响。（D-26）

## 6. 已知局限

- **分数是下界。** 视频里的口播广告、没有挂链接的品牌合作看不到。B 站不给商单视频打公开标识：视频详情接口里没有对应字段（D-38），视频页面上也没有（D-43）。内容层实际能看到的主要是置顶评论里的链接、文字披露和付费内容。所以商单做得多、但都在口播里的创作者，分数会明显偏低。
- **网页上看不到小店入口。** 店铺只能从简介和样本视频里的文字判断，开了小店却从不公开说明的人会被判为「无」（D-40、D-49）。
- **直播完全不覆盖。** 直播带货、打赏都发生在直播间里，空间页上看不到。
- **不看视频画面和口播**，只读标题、简介、置顶评论和平台标记。视频标签目前不采集（D-33）。
- **不读图片上的字。** 空间页横幅图里常写着「关注公众号」「某某小店」，这些是账号层信号，但读不到。
- **没有做分区归一化。** 数码区天然比生活区高。
- **权重是先验。**
- **C 档未经验证。** 判断软广需要行业经验，本项目的标注者不具备，所以没有去测它的准确率，而是用区间如实呈现不确定性。
- **校准样本小**，分位数和精确率本身误差较大。
- **取样按条数，不按时间。** 不同创作者的时间口径不同，也受大促季节影响；30 条的抽样误差没有算进区间（见 3.1）。
- 极端样本检验只能证明指数「分得开两头」，不能证明中间段的排序正确。

## 7. 调研依据

| 参照 | 做法 | 对本设计的影响 |
|---|---|---|
| HypeAuditor 受众质量分 | 1–100 分，4 个部分 / 15 个指标聚合后分档；公式与权重不公开 | 「多指标 → 分维度 → 聚合 → 分档」是通行结构；但黑盒无法满足「说明计算方式」，所以本项目做成白盒 |
| 新榜指数 | 原始值对照基准常数标准化后合成；强调标准化后跨维度可比、函数单调 | 先归一化再加权；基准应来自样本分布 |
| 赞助内容检测研究 | 用链接模式、UTM 参数、优惠码、披露用语识别商业内容；多数赞助内容未披露 | 证据特征有出处；必须设「疑似」档 |
| 《互联网广告管理办法》第九条（2023-05-01 施行） | 推销 + 附购买方式 → 应标「广告」 | B 档有客观定义 |
| 《广告法》第十六条、第十八条 | 医疗器械、药品、保健食品广告必须标明固定的提示语 | A 档新增「法定提示语」（D-42） |
| B 站变现渠道 | 花火商单、带货（蓝链、悬赏计划、小店）、充电、课堂、付费合集、直播、创作激励 | 第 1.1 节的表现清单 |
| OECD《综合指标构建手册》 | 理论框架 → 选指标 → 归一化 → 赋权 → 聚合 → 稳健性检验 | 整体方法论的骨架 |
