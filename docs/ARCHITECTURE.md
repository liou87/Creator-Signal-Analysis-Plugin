# 架构

## 数据流

```
B 站空间页
   │  内容脚本读取页面 + 请求公开接口
   ▼
CreatorSnapshot        创作者快照：账号信息 + 视频列表（标题、简介、标签、置顶评论）
   │  classify：规则（必有） + 模型（可选）
   ▼
Evidence[]             证据：哪条视频、哪一档、什么类型、原文引用、来源
   │  score：纯函数
   ▼
Report                 分数、区间、分档、子分、拆解、置信度
   │
   ▼
侧边栏界面
```

三个数据结构是模块之间唯一的接口。每一步只依赖上一步的输出。

## 模块

| 目录 | 职责 | 依赖浏览器 |
|---|---|---|
| `src/extract/` | 从 B 站页面和接口取数据，产出 `CreatorSnapshot` | 是 |
| `src/classify/` | `rules.ts` 关键词与正则；`llm.ts` 模型分类。产出 `Evidence[]` | 仅 `llm.ts` 需要网络 |
| `src/scoring/` | `score(snapshot, evidence) → Report`。参数全部在 `config.ts` | **否，纯函数** |
| `src/ui/` | 侧边栏：发起分析、进度、报告 | 是 |
| `entrypoints/` | 插件入口：后台脚本、内容脚本、侧边栏、设置页 | 是 |

评分引擎不依赖浏览器，是为了能用单元测试验证单调性、边界和可复现性，也方便校准时离线批量重算。

## 模型调用

- 由后台脚本发起（内容脚本受页面跨域限制）。
- 接口为 OpenAI 兼容格式，地址和 Key 在设置页配置，存浏览器本地存储。
- 一次分析的视频合并为一次请求。
- 输出为结构化数据，档位限定枚举值；引用原文必须是输入文本的子串，否则丢弃该条。
- 按「视频内容哈希 + 提示词版本」缓存。
- 没有配置 Key 时整个流程照常运行，C 档退化为关键词组合。
